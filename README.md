# «Ясно» — календарь дней с алкоголем и без него

Спокойное приложение для отметки дней: **был алкоголь / без алкоголя / не отмечено**.
Никаких серверов, аккаунтов и аналитики — только локальное хранилище.
По умолчанию включена **тёмная тема** (с возможностью переключения на светлую и смены названия в настройках).

В репозитории два приложения с **одной и той же бизнес-логикой**:

| Где | Что это | Хранилище |
| --- | --- | --- |
| **корень проекта** | веб-версия (React + Vite + Tailwind v4) — собирается в `dist/index.html` и открывается сразу | `localStorage` |
| **`mobile/`** | приложение **React Native + Expo (Expo Router, TypeScript)** | **expo-sqlite** |

Код серий и статистики лежит и в `src/core/*`, и в `mobile/src/core/*` (одинаковые файлы);
тесты прогоняют **один и тот же набор проверок против обеих копий**, чтобы они не разошлись.

## 1. Реализованные функции

**Экраны (нижняя навигация из четырёх разделов, интерфейс на русском):**

- **Сегодня** — текущая дата (день, месяц, год, день недели), статус дня
  («Алкоголь» / «Без алкоголя» / «Не отмечено») в виде штампа с иконкой и подписью,
  кнопки «Отметить без алкоголя» и «Отметить алкоголь», «Изменить отметку» /
  «Удалить отметку», необязательная заметка, текущая **подтверждённая серия**
  («N дней подряд отмечено без алкоголя»), **самая длинная серия**, «нить» из последних
  24 дней и явный текст о том, что сегодня ещё не отмечено.
- **Календарь** — режимы **«Месяц»** и **«Год (12 месяцев)»**, переключение месяцев и лет
  (в будущее не уходим), у каждого дня свой статус: **бутылочка** — день с алкоголем,
  **листик** — день без алкоголя, **пустое кольцо** — не отмечено; сегодняшний день обведён;
  будущие даты неактивны; под сеткой — **легенда** и итог месяца или года; нажатие на дату
  открывает модальное окно редактирования.
- **Статистика** — переключатель **Неделя / Месяц / Год**, три счётчика (дни с алкоголем, дни без
  алкоголя, **неотмеченные дни**), полосатая диаграмма долей (за неотмеченные — штриховка,
  а не «дни без алкоголя»), помесячная сводка за все 12 месяцев и карта всех 365/366 дней года,
  подпись про «N из M дней» и пустое состояние.
- **Настройки** — переключение **Тёмной / Светлой темы**, изменение названия приложения,
  сообщение о том, что **серверная синхронизация не реализована** и записи
  хранятся только локально; счётчики «записей в истории» и «0 серверов»; пояснение, что это
  дневник наблюдений, а не медицинский инструмент; **удаление всей истории с подтверждением**.

**Редактирование отметки**

- Модальное окно (веб) / модальный экран `app/edit/[date].tsx` (Expo) для любой даты:
  статус «Был алкоголь» или «Без алкоголя», необязательная заметка, «Сохранить»,
  «Удалить отметку», «Отмена».
- **Будущие даты отмечать нельзя** (показывается пояснение), прошлые — редактируются.
- Дубликатов быть не может: первичный ключ / unique по `date` + `upsert`.

**Данные**

- SQLite-таблица: `date TEXT PRIMARY KEY`, `status TEXT CHECK(...)`, `note TEXT`,
  `updated_at INTEGER`; запросы **параметризованные**, `INSERT ... ON CONFLICT(date) DO UPDATE`.
- Ключ дня — **локальная дата** `YYYY-MM-DD` (`date-fns/format`), `toISOString()` не используется.

**Правила серий** (`src/core/streaks.ts`, зеркально `mobile/src/core/streaks.ts`)

1. в серию попадают только явно отмеченные `alcohol_free`;
2. день с алкоголем прерывает серию;
3. неотмеченный день тоже прерывает серию;
4. если сегодня не отмечено — серия считается по отметкам до вчера, и это отдельно сказано;
5. если сегодня «алкоголь» — текущая серия 0, лучшая из прошлого сохраняется;
6. лучшая серия считается по всей истории и пересчитывается при любом изменении.

## 3. Установка и запуск

**Веб-версия**

```bash
npm install
npm run dev        # разработка
npm run build      # сборка в dist/index.html (один файл, всё внутри)
```

**Expo-приложение**

```bash
cd mobile
npm install
npx expo install --check   # выровнять версии пакетов под SDK
npx expo start             # затем i / a — iOS / Android, или скан QR
npm run typecheck          # tsc --noEmit
```

## 4. Проверки

```bash
npm run typecheck   # TypeScript для веб-версии                     ✅ пройдено
npm test            # vitest: 37 тестов                             ✅ 37/37
cd mobile && npx tsc --noEmit   # TypeScript для Expo               ✅ пройдено
cd mobile && npx expo export --platform android   # сборка Metro    ✅ бандл собран
npm run build       # продовая сборка веб                            ✅ 1 файл
```

Тесты покрывают: несколько подряд дней без алкоголя, прерывание серии алкоголем,
прерывание серии неотмеченным днём, «сегодня не отмечено» (счёт до вчера),
изменение и удаление отметки, пустую историю, локальные ключи дат (сверка с `toISOString()`),
подсчёт статистики (включая то, что неотмеченные дни ≠ дни без алкоголя), а также
сценарии самого интерфейса: старт с пустой историей, отметка дня, удаление через календарь,
удаление всей истории с подтверждением.

### Известные ограничения

- Веб-версия хранит данные в `localStorage` браузера: полноценный SQLite в одном HTML-файле
  недоступен, поэтому реализован **тот же интерфейс `DayRepository`** — в приложении на
  устройстве это expo-sqlite, в браузере — localStorage. Логика и SQL слои разделены.
- Веб-версия — это рабочая витрина продукта, а не замена мобильному приложению: нижняя
  навигация и safe-area рассчитаны на узкую колонку (макс. 560 px).
- Логика лежит в двух копиях (`src/core` и `mobile/src/core`), а не в общем пакете — так
  каждый проект остаётся самодостаточным; тесты гарантируют их поведенческое совпадение.
- `mobile/node_modules` уже установлен в этой среде; на чистой машине нужен `npm install`.
- Нет тестов под реальное устройство (Detox/Maestro) и нет E2E для SQLite — проверены
  юнит-логика, типы и сборка Metro.
